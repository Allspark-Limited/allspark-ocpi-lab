# Contributing

Thank you for improving Allspark OCPI Lab.

Anyone may propose a change from a branch or fork, using any development tool.
There is no contributor or agent allowlist. Review, merge, release, and hosted
operations follow [GOVERNANCE.md](GOVERNANCE.md).

Before proposing a change:

1. Keep all fixtures and evidence synthetic.
2. Do not add partner-specific exceptions or production credentials.
3. Add focused tests for protocol behavior and failure modes.
4. Run `npm test`, `npm run typecheck`, `npm run lint`, `npm run build`, and `npm audit`.
5. Document changes that affect configuration, migrations, security, or interoperability.

By contributing, you agree that your contribution is provided under this
repository's license. If a Developer Certificate of Origin sign-off is enabled,
follow the check's instructions.
